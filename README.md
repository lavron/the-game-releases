# The Game

Multiplayer open-world prototype for Linux and Steam Deck.

## Download

[Download The Game Launcher](https://github.com/lavron/the-game-releases/releases/download/launcher/TheGame.AppImage)

The launcher automatically downloads and updates the game.

### Linux

```bash
curl -fL -O https://github.com/lavron/the-game-releases/releases/download/launcher/TheGame.AppImage
chmod +x TheGame.AppImage
./TheGame.AppImage
```

### Steam Deck

1. Switch to Desktop Mode.
2. Download `TheGame.AppImage` using the link above.
3. Properties → Permissions → Is executable.
4. Run the AppImage.

For Gaming Mode, add the AppImage as a Non-Steam Game.

Launch Options: `%command% --cli`
