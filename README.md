# The Game

Multiplayer prototype for Linux and Steam Deck.

## Linux

```bash
curl -fL -O https://github.com/lavron/the-game-releases/releases/download/v0.0.2/TheGame.AppImage
chmod +x TheGame.AppImage
./TheGame.AppImage
```

## Steam Deck

1. Switch to Desktop Mode.
2. [Download TheGame.AppImage](https://github.com/lavron/the-game-releases/releases/download/v0.0.2/TheGame.AppImage).
3. Right-click → Properties → Permissions → Is executable.
4. Run the AppImage.

For Gaming Mode, add the AppImage as a Non-Steam Game.

Launch Options: `%command% --cli`
